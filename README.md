# LLMChatFlow

A sophisticated workflow engine for LLM-based chatbots, featuring advanced memory management, structured context construction, and token-aware prompt assembly.

## Key Features

*   **Hybrid Memory System**: Combines short-term sliding windows, dynamic summarization, and semantic search (vector store).
*   **Token Budgeting**: Smart token allocation for system prompts, history, and RAG context.
*   **Structured Context**: Dynamically builds context based on conversation state and available data.
*   **Modular Architecture**: Clear separation of concerns (Session, Memory, Workflow, LLM, Adapters).
